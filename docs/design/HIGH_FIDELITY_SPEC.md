# TRACE High-Fidelity Spec (Phase 1)

## Visual direction
- Quiet dark surfaces (#0d111b / #111726)
- Primary text warm white (#f5f7fb)
- Secondary text cool gray (#9aa4bb)
- Accent violet/blue (#6f7dff)
- Selection/arrow coral (#ff7f61)

## Typography and spacing
- Geist Sans system, fallback to ui-sans-serif.
- 4/8px spacing rhythm.
- Radius scale: 8/12/16.

## Interaction style
- Minimal 160ms transitions.
- Focus rings visible on all keyboard-focusable controls.
- Iconography from Lucide only.

## Accessibility targets
- Contrast >= WCAG AA for text and controls.
- Keyboard access for upload, selection mode, point nudge, analyze action.
- Clear SR labels for icon-only controls.
