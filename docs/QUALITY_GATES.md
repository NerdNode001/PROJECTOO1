# Quality Gates

## Required commands
- `npm run lint`
- `npm run typecheck`
- `npm run test`
- `npm run build`

## Manual checks for Phase 1
- Upload/sample flow works on workspace.
- Point and rectangle selection behave correctly after resize/zoom.
- Keyboard point nudge and Escape clear behavior works.
- Mobile inspector and nav are reachable.

## Risks deferred to later phases
- Auth, persistence, and private storage enforcement.
- Real provider integration, cost control, and rate limiting.
- Video frame extraction and processing.
